# LP4_miniproject

This repository contains the LP4 miniprojects. Each project lives in its own top-level folder so they can be maintained and demonstrated independently.

## Projects

- [Digital Image Forensics](digital-image-forensics/README.md) — PixelProof, a local web app for image metadata, ELA, noise, and copy-move analysis.
- [CovidCare STQA Mini Project](covid-stqa-project/README.md) — COVID-19 information and testing portal with PHP/MySQL and Selenium/TestNG QA coverage.
